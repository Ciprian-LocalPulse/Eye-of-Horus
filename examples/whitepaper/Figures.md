## Contributing a Figure

A contributed figure should be accompanied by the source data or script used to generate it (in keeping with the reproducibility standard set for benchmarks in [`PERFORMANCE.md`](../PERFORMANCE.md)) wherever the figure depicts anything more than static illustrative geometry, so that it can be regenerated as the underlying model evolves.
