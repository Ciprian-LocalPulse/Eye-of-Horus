# Website

This directory is a static documentation website scaffold for Eye of Horus, intended to make the project's documentation, specification, and white paper discoverable to newcomers without requiring them to browse the source repository directly.

## Planned Scope

- A landing page summarizing the project's vision and current status, mirroring the honesty conventions of [`README.md`](../README.md) rather than presenting a more polished-sounding but less accurate picture.
- Rendered, navigable versions of the specification set in [`spec/`](../spec/README.md) and the [white paper](../whitepaper/README.md).
- A published build of the [language book](../book/README.md) once it has enough chapters to be useful as a standalone site.
- A link to the project's donation page ([`DONATE.md`](../DONATE.md)) and community channels ([`SUPPORT.md`](../SUPPORT.md)).

## Status

Static documentation scaffold; no generated site is published from this directory yet. Website work is tracked as part of [`ROADMAP.md`](../ROADMAP.md) Phase 3, after the documentation it would publish (the specification and book) reaches sufficient stability that the site does not need to be substantially restructured shortly after launch.

## Current Website

The project's existing website, distinct from the static scaffold in this directory, is linked from [`README.md`](../README.md) at [https://agentflow-enterprise.com](https://agentflow-enterprise.com).
