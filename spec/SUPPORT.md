# Support

Eye of Horus is maintained as an open-source research project by a small team, currently led by its founding author. Support channels below are matched to the kind of question being asked, so that discussion happens in the venue best suited to resolve it.

## Community Support

- **GitHub Issues** — use for bugs in the existing Rust scaffold, documentation problems (including ambiguity between implemented, planned, and speculative content, per [Design Principle 1](DESIGN_PRINCIPLES.md#1-honesty-before-spectacle)), and small, well-scoped design questions.
- **GitHub Discussions** — use for open-ended ideas, questions about the project's research direction, or proposals that are not yet mature enough to be a formal RFC.
- **RFCs** — use for language features and semantic changes, following the process in [`RFC_PROCESS.md`](RFC_PROCESS.md); an RFC, not an issue or discussion thread, is the correct venue for anything that would change [`spec/LANGUAGE_SPEC.md`](spec/LANGUAGE_SPEC.md) or [`spec/SEMANTICS.md`](spec/SEMANTICS.md).

## Before You Ask

Many common questions are already answered directly in [`FAQ.md`](FAQ.md), including whether the project is production ready, what exists today versus what is planned, and whether the phi-pi memory model provides security. Checking there first is likely to be faster than waiting for a reply.
