# Suggested Repository Topics

The following topic tags are suggested for repository hosting platforms that support topic-based discovery (for example, GitHub's repository topics feature), so that Eye of Horus is discoverable by researchers and practitioners working in adjacent areas:

`programming-language` · `compiler` · `interpreter` · `rust` · `geometry` · `computational-geometry` · `spatial-computing` · `geometry-native` · `virtual-machine` · `parser` · `lexer` · `ast` · `language-design` · `formal-semantics` · `systems-programming` · `3d` · `mathematics` · `research` · `developer-tools` · `open-source` · `esolang` · `eye-of-horus`

## Rationale for Selection

These tags are chosen to reflect the project's actual scope as described in [`VISION.md`](VISION.md) and the [white paper](whitepaper/eye-of-horus-whitepaper.md): a research-stage, geometry-native programming language with a Rust reference implementation, formal semantics, and stated kinship with the esoteric-language tradition (Befunge and Piet are cited as lineage in the white paper's positioning section). Tags implying a finished, production-ready, or commercially competitive product (for example, terms suggesting performance leadership or industrial adoption) are deliberately excluded, consistent with [Design Principle 1](DESIGN_PRINCIPLES.md#1-honesty-before-spectacle).
