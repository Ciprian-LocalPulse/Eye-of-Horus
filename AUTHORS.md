## Recognition Policy

Contributors are added to this file as they make sustained, substantive contributions to the project — code, specification text, RFCs, documentation, or governance work — rather than automatically for a single small pull request, which is instead recognized through the hosting platform's own contributor attribution. A contributor who is unsure whether their contribution qualifies for listing here is welcome to ask; see [`SUPPORT.md`](SUPPORT.md) for contact channels.

This file is distinct from [`ACKNOWLEDGEMENTS.md`](ACKNOWLEDGEMENTS.md), which credits external prior work and communities that informed the project's design, rather than individuals who have directly contributed to this repository.
