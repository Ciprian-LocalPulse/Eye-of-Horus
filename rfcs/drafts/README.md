# Draft RFCs

Use this directory for in-progress RFC drafts, following the process described in [`RFC_PROCESS.md`](../../RFC_PROCESS.md).

To start a new draft, copy [`../0000-template.md`](../0000-template.md) into this directory under a descriptive filename (`NNNN-short-title.md`, using the next available number), and open a pull request once the motivation, design, drawbacks, and alternatives sections are complete enough to invite substantive review. Drafts that are accepted are moved to [`accepted/`](../accepted/README.md); drafts that are rejected are closed with the reasoning recorded in the associated pull request rather than deleted from project history.
