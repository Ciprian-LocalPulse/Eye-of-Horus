# Accepted RFCs

This directory will contain RFCs that have been formally accepted through the process in [`RFC_PROCESS.md`](../../RFC_PROCESS.md) and may proceed to implementation.

The project's first accepted RFC, [RFC 0001: Phi-Pi Addressing for the Spatial Field](../0001-phi-pi-addressing.md), is currently kept at the top level of the `rfcs/` directory rather than in this folder, as the canonical worked example other RFCs are measured against. Future accepted RFCs will be moved here from [`drafts/`](../drafts/README.md) upon acceptance.
